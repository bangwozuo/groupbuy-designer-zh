# 连接器：团购设计师

> 连接器说明**只有文档，没有代码**。本资产是纯提示词资产，连接器用于告诉你
> **数据从哪来、怎么合规地来**。

---

## 一、合规总原则（两条路，别无第三条）

| ✅ 允许 | ❌ 禁止 |
|--------|--------|
| **官方 API**（平台授权范围内） | 爬取需登录的私密数据 |
| **用户自行导出的数据**（商家后台、个人账号导出） | 协议机器人 / 批量刷取 |
| 公开榜单、公开热榜的只读访问 | 刷量、刷评、刷粉 |
| 用户自有账号的授权 API | 绕过平台风控的任何手段 |

---

## 二、本员工涉及的数据源

| 连接器 | 接入方式 | 数据内容 |
|--------|---------|---------|
| [抖音开放平台](douyin-open-api.md) | 官方 API | 公开视频数据、团购核销（授权范围内） |
| [大众点评 / 美团](dianping-meituan.md) | 用户导出 / 商家后台 | 评价、评分、团购核销 |
| [商品与订单后台](product-order-backend.md) | 用户导出 / 商家后台 | 商品信息、订单、售后记录 |
| [微信 / 企业微信](wechat-wecom.md) | 官方 API | 客户标签、会话（授权范围内） |

---

## 三、字段映射与降级

| 情况 | 做法 |
|------|------|
| 有官方 API | 直接调用，取授权范围内字段 |
| 无 API 但有后台 | 用户自行导出 CSV / Excel，人工导入 |
| 两者都无 | 用公开数据 / 手工整理，**不做爬取** |

---

## 四、数据脱敏要求

- 手机号、身份证、地址、支付信息**一律不录入**
- 客户昵称建议替换为代号
- 导出的原始数据**不要提交进本仓库**（`.gitignore` 已忽略 `data/`）
