## 能力描述

美团/抖音扣点与上架规则查询

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `query` | string | ✅ | 检索关键词 |
| `knowledge` | string | ✅ | 可检索的知识内容（粘贴的材料或已挂载的知识库） |

## 输出规格

知识检索与问答

- `answer`：基于知识范围的回答
- `citations`：每条结论对应的知识条目
- `gaps`：知识范围中未覆盖、需补充的内容

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 按上方「输入规格」提供数据
4. 得到符合「输出规格」的结果

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |
| **Claude** | 新建 Project → Instructions → 粘贴 `prompt.txt` |
| **ChatGPT** | 新建 GPT → Instructions → 粘贴 `prompt.txt` |

## 边界（不做的事）

- ❌ 编造数据、案例或效果承诺
- ❌ 使用违反《广告法》的极限词
- ❌ 生成诱导好评、刷量、删差评等违规内容
- ❌ 执行或建议任何绕过平台规则的操作
- ❌ 涉及资金操作或代替用户做最终决策
- ❌ 处理超出本职能力范围的请求（应明确说明并建议转其他技能）

## 调用示例

**输入**：

```json
{
  "query": "我准备在美团上架一款到店自助双人套餐（团购价168元），同时在抖音也上架同款。两款平台的扣点分别是多少？套餐有效期和核销规则上有什么要注意的？",
  "knowledge": "用户粘贴材料《2026年9月整理·美团与抖音本地生活入驻备忘》：【条目A】美团到店餐饮团购技术服务费：到店自助类目费率为4.5%+0.6元/单，下单未核销全额退款时不收技术服务费。【条目B】抖音本地推·团购商品技术服务费：到店餐饮类目统一2.5%，达人带货另计佣金（由商家自行设置，常见5%-10%）。【条目C】美团团购有效期规则：单次团购券最长有效期不超过90天，未核销可随时申请退款，过期未用自动退款。【条目D】抖音团购券规则：有效期由商家设置，最长不超过1年；用户购买后7天内未核销可无理由退款，过期未核销自动退款。【条目E】两平台均要求：套餐页必须明示使用时间、不可用日期、是否需要预约、单人限购数量。"
}

```

**输出**：

```markdown
## 回答

**一、两款平台的扣点（按你粘贴的《2026年9月整理·美团与抖音本地生活入驻备忘》）**

- 美团：到店自助类目技术服务费为 4.5% + 0.6元/单（条目A）。团购价168元时约为 168×4.5%=7.56元 + 0.6元 = 约8.16元/单；若未核销全额退款，则不收技术服务费。
- 抖音：到店餐饮类目技术服务费统一 2.5%（条目B），168元对应约 4.2元/单；若达人带货另计佣金，佣金率由你自行设置，备忘中列示常见区间为 5%-10%。

**二、套餐有效期与核销注意事项**

- 美团（条目C）：团购券最长有效期不超过 90 天；未核销可随时申请退款，过期未用自动退款。
- 抖音（条目D）：有效期由商家自设，最长不超过 1 年；用户购买后 7 天内未核销可无理由退款，过期未核销自动退款。
- 上架信息（条目E）：两平台都要求套餐页明示使用时间、不可用日期、是否需要预约、单人限购数量。你的双人套餐上架时这四项缺一不可。

**三、对你这款 168 元到店自助双人套餐的直接提示（仅基于上述材料）**

- 抖音扣点（2.5%）低于美团（4.5%+0.6元/单），但若走达人带货，需把 5%-10% 的佣金计入综合费率再比价。
- 美团侧需在 90 天有效期内规划售卖节奏；抖音侧注意 7 天无理由退款带来的订单回落。

## 出处

1. 条目A（美团到店自助类目技术服务费 4.5%+0.6元/单；未核销全额退款不收费）
2. 条目B（抖音到店餐饮技术服务费 2.5%；达人佣金商家自设，常见5%-10%）
3. 条目C（美团团购券有效期最长90天；未核销可退，过期自动退款）
4. 条目D（抖音团购券有效期最长1年；购买后7天未核销可无理由退款，过期自动退款）
5. 条目E（两平台套餐页须明示使用时间、不可用日期、是否需预约、限购数量）

## 知识缺口

1. 材料未包含美团/抖音 2026 年 10 月之后是否调整费率的最新公告，上线前需以平台商家后台当期公示为准。
2. 材料未说明"到店自助"类目在抖音侧是否有独立费率，还是直接套用到店餐饮统一 2.5%。
3. 材料未涉及两平台对自助餐类目的保证金、结算账期及退款资金流细节。

> 本内容为 AI 生成内容，仅基于用户粘贴材料作答；平台规则可能更新，正式上架前需人工在商家后台核实。


```
