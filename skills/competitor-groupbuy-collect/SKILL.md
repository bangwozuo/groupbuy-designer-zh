## 能力描述

商圈竞品团购信息抓取与结构化（BusinessConnector 摘录解析）：

1. **结构化解析** —— 把用户手摘记录拆成 店名 / 套餐类型 / 原价 / 现价 / 内容限制，单条缺失字段不补默认值，列缺口清单
2. **折扣率计算** —— 折扣率 = 现价 ÷ 原价 × 100%（保留 1 位小数），低于 50% 标「深折扣」
3. **价格带分档** —— <100 元（引流带）/ 100-200 元（主力带）/ >200 元（利润带），逐带统计条数
4. **确定性统计落盘** —— 单次最多 10 条，超出按现价从低到高截断；产出 CSV / JSON / MD 三件产物

业务解读与竞争策略建议由模型按 prompt.txt 完成，数值一律以脚本输出为准。

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 按上方「输入规格」提供数据
4. 得到符合「输出规格」的结果

### 方式二：带脚本（推荐，产出真实文件）

```bash
python <SKILL_DIR>/scripts/competitor_groupbuy_collect.py --input examples/input.json --outdir out
python <SKILL_DIR>/scripts/competitor_groupbuy_collect.py --demo --outdir out
```

**分工**：脚本做记录解析、折扣率、价格带分档与 CSV/JSON/MD 落盘；模型做语境解读与竞争策略建议。

## 边界（不做的事）
