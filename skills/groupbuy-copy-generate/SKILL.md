# 团购文案生成

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_local_04_sk03` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 团购设计师 |
| 能力族 | — |
| 复杂度 | `S` |
| 阶段 | `P1` |
| 复用度 | 中（探店编导 S3 复用） |
| 资产形态 | 纯提示词（无运行时依赖） |

## 能力描述

套餐卖点文案

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `brief` | string | ✅ | 任务简述（产品 / 主题 / 目标） |

## 输出规格

文案撰写

- `title`：3 个备选标题，标注推荐项
- `body`：完整文案，分段清晰
- `notes`：结构安排与取舍理由

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 按上方「输入规格」提供数据
4. 得到符合「输出规格」的结果

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |
| **Claude** | 新建 Project → Instructions → 粘贴 `prompt.txt` |
| **ChatGPT** | 新建 GPT → Instructions → 粘贴 `prompt.txt` |

## 边界（不做的事）

- ❌ 编造数据、案例或效果承诺
- ❌ 使用违反《广告法》的极限词
- ❌ 生成诱导好评、刷量、删差评等违规内容
- ❌ 执行或建议任何绕过平台规则的操作
- ❌ 涉及资金操作或代替用户做最终决策
- ❌ 处理超出本职能力范围的请求（应明确说明并建议转其他技能）

## 调用示例

**输入**：

```json
{
  "brief": "为成都「锦城巷串串香」春熙路店撰写抖音团购上架文案，面向25-35岁年轻上班族与大学生，目的是促进工作日晚市到店消费、提升新客进店量",
  "key_points": "① 双人套餐88元（原价136元）：含锅底任选1份、签签荤素各40支、冰粉2份、酸梅汤1扎；② 全城门店晚市通用，周一至周五17:00后到店免预约直接核销；③ 门店为本地开了8年的社区老店，牛油锅底每日现炒，签签每日冷链直达；④ 有效期90天，过期自动退款"
}

```

**输出**：

```markdown
## 标题

1. 【推荐】成都春熙路开了8年的串串香老店，双人88元晚市畅签！
2. 工作日晚饭不将就：牛油现炒锅底+80支签签，双人只要88
3. 加班后的犒劳：免预约串串双人餐，酸梅汤冰粉都配齐

## 正文

加班到七点，胃里空空的，最想要的就是一锅热气腾腾的红汤。

锦城巷串串香·春熙路店，本地开了8年的社区老店。牛油锅底每天现炒，签签每日冷链直达——不是料理包，是你在成都街头该吃到的味道。

【双人套餐 88元 | 原价136元】
· 锅底任选1份（牛油/番茄/菌汤）
· 签签荤素各40支，共80支
· 冰粉2份
· 酸梅汤1扎

周一到周五17:00后到店，免预约、直接核销，下班路上顺路就能吃。套餐有效期90天，过期未用自动退款，不怕囤着浪费。

25-35岁的你，工作日的晚上也值得被一顿现炒锅底认真对待。点击抢购，今晚就去涮。

## 创作说明

1. 标题主打"8年老店+价格锚点（88元双人）"，用具体年头与门店位置建立真实感，推荐项把人群（上班族/学生）关心的"晚市+免预约"前置。
2. 正文按"场景钩子→信任背书→套餐清单→使用规则→行动号召"五段推进：先切加班场景引发共鸣，再用"现炒锅底/冷链直达"回应品质疑虑，套餐内容逐项列清避免歧义，规则信息（免预约时段、90天有效期、自动退款）如实呈现降低决策顾虑，结尾给明确行动指令。
3. 取舍：未使用"巷子深处宝藏小店"这类无法验证的修饰，未承诺"秒杀全网价格"等极限表述；所有数据（88元、80支、90天）均来自需求要点。

> 本内容为 AI 生成内容，正式发布前需人工确认。


```
